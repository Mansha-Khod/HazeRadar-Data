# Data Pipeline

This module collects, processes, and stores environmental data used by AirCast.

## Data Sources

- NASA FIRMS
- OpenWeatherMap
- AQICN
- Open-Meteo

## Features

- Automated data collection
- Data cleaning
- Feature generation
- Database storage

## Stored Data

- Weather data
- AQI data
- Fire hotspot data
- PM2.5 readings

## Tech Stack

- Python
- Pandas
- Supabase
- Cron jobs
